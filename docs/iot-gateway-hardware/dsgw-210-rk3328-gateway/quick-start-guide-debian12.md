# Quick Start Guide(Debian12)

# 1. Introduction
This Quick Start Guide explains the basics: <br />
 - how to connect and set up your target on the network<br />
 - how to install the SDK<br />
 - how to modify and build the firmware images<br />
The Linux Software Developer's Kit (SDK) is an embedded hardware and software suite that enables Linux developers to create applications on Dusun's gateway. <br />


# 2. Gateway Information
This section describes the gateway's basic resource infomation and interfaces.<br /><br />

## 2.1 Basic information

- Processor: RK3328 (ARM64)<br />
- Supply: DC-5V/2A<br />
- RAM: DDR2 2G <br />
- EMMC: 8G/16G/32G<br />
- Ethernet: WAN RJ45/10M/100M<br />
- Bluetooth: ERF32BG21<br />
- Zigbee: EFR32MG1B232<br />
- Zwave: ZG130S<br />
- LTE: EG25/..<br />
- LoraWan: SX1302<br />
- USB<br />
- WIFI: RTL8821CS<br />

# 4. SDK Download And Compile
This section describes how to download the sdk and compile it.

## 4.1 SDK Envirment Prepare
Compilation environment: ubuntu20.04/ubutun22.04
Openwrt's compilation tool is automatically generated by SDK built, no additional
installation is required

- make sure your machine have enough ram (2G+)

## 4.1 SDK Download
Get the source code from Dusun FTP server uncompress it under your work directory.
For example:

```shell
mkdir -p ~/workdir/ubuntu210
tar zxvf DSGW-210-DB12-SDK_AV1.0.4.tar.gz -C /workdir/debian12/
cd ~/workdir/debian12
```

## 4.2 SDK Compile
```shell
cd ~/workdir/ubuntu210
./build.sh // or sudo ./build.sh 

./build.sh kernel //compile kernel
./build.sh uboot  //compile uboot
./build.sh updateimg //generate update.img 
```

## 9.2 Button
This board has one button can used by software, when pressed, the system will auto call the button script in the `/etc/rc.button/battery_power_switch`

here are two incomming parameters

- SEEN:  this is the time, unit seconds
- ACTION: this is the action, it will we `pressed` or `release`

see the example has one function in the button script
- firts is the long pressed 3 seconds to close the battery power supply

```shell
#!/bin/sh

led_off() {
  echo none > /sys/class/leds/$1/trigger
  echo 0,0,0 > /sys/class/leds/$1/brightness
}

led_blink() {
  echo timer > /sys/class/leds/$1/trigger
  echo 100 > /sys/class/leds/$1/delay_off
  echo 100 > /sys/class/leds/$1/delay_on
  echo 0,$2,0 > /sys/class/leds/$1/rgb_value
}

[ "$ACTION" = "pressed" ] && {
        logger "battery_power_switch pressed, SEEN:$SEEN"
        exit 0
}


[ ! "$ACTION" = "released" ] && {
        exit 0
}


logger "battery_power_switch released, SEEN:$SEEN"
[ -e /etc/rc.button/double_click ] && /etc/rc.button/double_click

[ $SEEN -gt 15 ] && {
        logger "reset factory!!!!"
        #led_blink led0 1
        #led_blink led1 1
        #led_blink led2 1
        #led_blink led3 1
        #led_blink led4 1
        #led_blink led5 1
        kill -9 `pidof -x ds_net_led.sh`
        kill -9 `pidof -x ds_reapp.sh`
        dsled g blink_fast
        sleep 2
        #led_off led0
        #led_off led1
        #led_off led2
        #led_off led3
        #led_off led4
        #led_off led5
        #touch /factoryreset
        #fsreset
        factory_restore.sh
        reboot
        exit 0
}


[ $SEEN -gt 3 ] && {
        logger "battery switch ing"
        val=`i2cget -f -y 0 0x6a 0x09`
        ret=$?
        [ "$ret" = "0" ] && {
                if [ "$val" = "0x20" ]; then #
                        logger "open battery !!"
                        i2cset -f -y 0 0x6a 0x09 0x44
                else
                        logger "close battery !!"
                        i2cset -f -y 0 0x6a 0x09 0x20
                fi
        }
        exit 0
}


```

## 9.4 wifi
This gateway  have a 2.4g/5.0g radio, it worked at sta mode and ap mode:

- ap config

```shell
root@DSGW-210:~# cat /etc/config/wireless 

config 'wifi-iface' 'ap0'
        option 'network' 'lan'
        option 'mode' 'g'
        option 'encryption' 'psk2'
        option 'key' '12345678'
        option 'ifname' 'ath0'
        option 'up' '1'
        option 'disabled' '0'
        option 'ssid' 'Dusun-27777A'
        option 'channel' '1'

root@DUSUN:~# cat /etc/systemd/network/21-ap.network 
[Match]
Name=wlan1

[Network]
Address=192.168.10.1/24
DHCPServer=true
IPMasquerade=ipv4

[DHCPServer]
PoolOffset=100
PoolSize=20
EmitDNS=yes
DNS=9.9.9.9
```

- sta config

```shell
root@DSGW-210:~# cat /etc/config/wireless 
config 'wifi-iface' 'sta0'
        option 'device' 'radio0'
        option 'network' 'wwan0'
        option 'mode' 'sta'
        option 'Refresh' 'Refresh'
        option 'ssid' 'AAAAAA'
        option 'key' 'dl123456'
        option 'encryption' '[WPA-PSK-CCMP][WPA2-PSK-CCMP][ESS]'
        option 'disabled' '1'
		
root@DUSUN:~# cat /etc/systemd/network/21-sta.network 
[Match]
Name=wlan0
[Network]
DHCP=yes

[DHCPv4]
RouteMetric=20
```

- when you complete the basic config, you can use luci2sys.sh script to valid it.

```shell
luci2sys.sh sync - sync the config 
luci2sys.sh lan  - reload lan(ap config)
luci2sys.sh wan  - reload wan(eth0 config)
luci2sys.sh wifi - reload sta(sta config)
```
